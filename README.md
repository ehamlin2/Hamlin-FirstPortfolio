# Hamlin-FirstPortfolio

MY FIRST PORTFOLIO

Fables & Frames Photography
A responsive, multi-page portfolio website for Fables & Frames Photography. The site uses a mobile-first layout, switching from columns to rows on screens 680px and larger. 

The site includes pages:
index.html: Home page with an introduction, featured work, experience, equipment, education, and contact links
people.html: Portfolio gallery for graduation, family, maternity, and headshot photography
places.html: Portfolio gallery for Japan, Charleston, Malaga, and Yosemite
pets.html: Portfolio gallery for rescue dogs, pet photography, and wildlife

The HTML is semantic and validated. 
The CSS is responsive. 
Page content and theme provided by AI. 
All HTML and CSS is created by the student.
