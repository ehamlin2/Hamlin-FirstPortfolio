# Hamlin-FirstPortfolio
MY FIRST PORTFOLIO

Fables & Frames Photography
A responsive, multi-page portfolio website for Fables & Frames Photography. The site uses a mobile-first layout, switching from columns to rows on screens 680px and larger. The site include portfolio photos of Places, People, and Pets, each shown with their own page.
The HTML is semantic and validated. 
The CSS is responsive. 
There is no Javascript. 
Page content theme provided by AI. 
All HTML and CSS is created by the student.
